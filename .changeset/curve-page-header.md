Add `CurvePageHeader` (`curve-page-header`): the top section of a page, composed from parts (media with `default`/`icon`/`image` variants, title, badges, description, page actions and tab navigation) next to the existing breadcrumb. On narrow containers the actions move below the description and extra actions collapse into a "More actions" menu.
