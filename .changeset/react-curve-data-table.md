New `CurveDataTable` component: the ready-made data table that Angular already had. It shows search, column toggles, row selection, sorting, row actions and paging, configured with the same column classes as Angular (`CurveDataTableSelectionColumn`, `CurveDataTableStringColumn`, `CurveDataTableImageColumn`, `CurveDataTableActionColumn`). Row actions call `onRowActionTriggered`. The search field has an accessible name and the sortable header text lines up with the cells.
