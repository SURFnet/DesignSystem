# Naamloze knoppen

Een [screenreadergebruiker](?path=/docs/toegankelijkheid-introductie--verschillende-beperkingen-persona-s)
navigeert onder meer via een lijst met knoppen. Zonder toegankelijke naam blijft daar alleen de rol
over: "knop".

## Het probleem

Een icoonknop is visueel volstrekt duidelijk: een prullenbak, een kruis, een potlood. Voor wie de
pagina beluistert, is er geen prullenbak. Er is een bedienbaar element zonder naam.

Hetzelfde gebeurt bij een invoerveld zonder `<label>`, een link die alleen een icoon is, of een knop
waarvan de tekst in een `svg` of achtergrondafbeelding zit. De toegankelijke naam is leeg, en de
gebruiker moet gokken.

Een `div` met een klikafhandelaar is nóg erger: hij staat niet eens in die knoppenlijst. Dat staat
bij [De eerste regel van ARIA](?path=/docs/toegankelijkheid-do-s-en-don-ts--de-eerste-regel-van-aria).

## De oplossing

Elk bedienbaar element heeft een naam nodig. De zichtbare tekst ís de beste naam. Alleen als die er
niet is, voeg je er een toe.

```html
<!-- Niet doen: voorgelezen als "knop" -->
<button>
  <svg><!-- prullenbak --></svg>
</button>

<!-- Wel doen: benoem de knop, verberg de decoratie -->
<button type="button" aria-label="Factuur verwijderen">
  <svg aria-hidden="true" focusable="false"><!-- prullenbak --></svg>
</button>
```

Voorkeursvolgorde:

1. Zichtbare tekst in de knop of link.
2. Een `<label>` dat aan het veld gekoppeld is.
3. `aria-labelledby` naar tekst die al op het scherm staat.
4. `aria-label` alleen bij icoon-only bediening.

Controleer in DevTools → **Elements** → **Accessibility** → **Name**. Is Name leeg, dan is het
element naamloos. Hoe je die teksten schrijft, staat bij
[Voor tekstschrijvers](?path=/docs/toegankelijkheid-inhoud-en-bediening--voor-tekstschrijvers).
Meer over benoemen bij
[ARIA correct gebruiken](?path=/docs/toegankelijkheid-do-s-en-don-ts--aria-correct-gebruiken).
