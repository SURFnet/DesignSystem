# Inhoud en bediening

De [Do's en don'ts](?path=/docs/toegankelijkheid-do-s-en-don-ts--overzicht) gaan over wat je in de
opmaak fout doet. Deze sectie gaat over wat je _zet_: de tekst, de media, en de manieren waarop iemand
de pagina bedient als de muis of het volle scherm wegvalt.

Curve levert hier bijna niets kant-en-klaar. Een skiplink, een alt-tekst, een ondertiteling en een
aanraakdoel van 44 pixels zijn keuzes in het product, niet in een knopcomponent.

| Pagina                                                                                         | Voor wie                         | Wat je meeneemt                                                    |
| ---------------------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| [Voor tekstschrijvers](?path=/docs/toegankelijkheid-inhoud-en-bediening--voor-tekstschrijvers) | Iedereen die woorden zet         | Linktekst, alt-tekst, foutmeldingen, fouten toestaan               |
| [Video en audio](?path=/docs/toegankelijkheid-inhoud-en-bediening--video-en-audio)             | Iedereen die media publiceert    | Ondertiteling, transcript, geen geluid-alleen                      |
| [Skiplinks](?path=/docs/toegankelijkheid-inhoud-en-bediening--skiplinks)                       | Wie een volledige pagina bouwt   | Wat een skiplink is, hoe je hem maakt, hoe je hem test             |
| [Touch en vergroting](?path=/docs/toegankelijkheid-inhoud-en-bediening--touch-en-vergroting)   | Wie ontwerpt of een layout bouwt | Klikdoelen, telefoon, pagina-zoom, inzoomen op een afbeelding      |
