# Automatische beweging

Onverwachte beweging eist aandacht op. Voor wie
[ADHD heeft, snel overprikkeld raakt, of vestibulaire klachten heeft](?path=/docs/toegankelijkheid-introductie-verschillende-beperkingen-persona-s--overzicht)
is dat geen sfeer, het is een blokkade.

## Het probleem

Een carrousel die vanzelf doorschuift, een parallax-header, een loader die pulseert, een video die
[automatisch afspeelt](?path=/docs/toegankelijkheid-introductie-verschillende-beperkingen-persona-s-blind-screenreadergebruiker--video-die-automatisch-afspeelt),
confetti bij een succesmelding: de pagina beweegt terwijl iemand probeert te lezen of een veld in
te vullen.

WCAG 2.2.2 (Pause, Stop, Hide) eist dat beweging die langer dan vijf seconden duurt, te pauzeren of
uit te zetten is. Flitsen kunnen een aanval uitlokken (2.3.1). `prefers-reduced-motion` is het
signaal van het besturingssysteem dat iemand minder beweging wil: het negeren is een keuze.

## De oplossing

Geen beweging die de gebruiker niet heeft gevraagd. Respecteer `prefers-reduced-motion`.

```css
.carousel {
  animation: slide 12s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  .carousel {
    animation: none;
  }
}
```

- Carrousels starten niet vanzelf, of pauzeren bij focus en hebben een pauze-knop.
- Succes mag een korte, kleine overgang zijn, geen confetti-explosie.
- Loaders mogen bewegen; ze horen te stoppen of stiller te worden bij reduced motion.
- Curve-componenten volgen dit token al. Voeg geen eigen `animate-*` toe zonder de media query.

Zet **Verminder beweging** aan in je systeeminstellingen en herlaad. Blijft alles bewegen, dan is
het niet af. Zie
[Handmatig testen](?path=/docs/toegankelijkheid-je-werk-testen--handmatig-testen).
