# Jargon

Wie [dyslexie heeft, de term voor het eerst ziet, of haast heeft](?path=/docs/toegankelijkheid-introductie--verschillende-beperkingen-persona-s)
kan een slimme zin niet decoderen. Automatische tools zien dit niet: de opmaak is geldig, de woorden
niet.

## Het probleem

Interne afkortingen, woordgrappen, metaforen, en werkwoorden die nét naast het gewone woord liggen
("initiëren" in plaats van "aanvragen") kosten werkgeheugen. Koppen als "Overig" of "Meer" zeggen
niets als je alleen de koppenlijst hoort. Acht keer "Lees meer" is dezelfde valkuil voor wie van
link naar link springt.

Jargon is toegestaan als je lezer het vak spreekt. Het is een probleem als je niet zeker weet dat
iedereen het kent.

## De oplossing

Schrijf alsof de lezer de vorige stap alweer is vergeten.

- Korte zinnen. Eén gedachte per zin.
- Het gewone woord als het de lading dekt.
- Koppen die een inhoudsopgave vormen als je de rest wegdenkt: "Factuur downloaden", niet "Overig".
- Leg een vakterm één keer uit, of vermijd hem.
- Linktekst die los van de context klopt.

| In plaats van                    | Schrijf                                           |
| -------------------------------- | ------------------------------------------------- |
| Initiëren                        | Aanvragen                                         |
| Lees meer                        | Lees het onderzoeksrapport over hybride onderwijs |
| De handleiding vind je [hier](#) | [Handleiding aanvragen](#)                        |

Dit is werk voor wie de woorden zet, niet voor een knopcomponent. De rest staat bij
[Voor tekstschrijvers](?path=/docs/toegankelijkheid-inhoud-en-bediening--voor-tekstschrijvers).
