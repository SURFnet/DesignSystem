# Regelgeving

Voor de organisaties waarvoor Curve gemaakt is, is voldoen aan de WCAG-normen niet vrijblijvend. Nederlandse overheidsinstellingen en publiek gefinancierd onderwijs vallen onder de Europese norm EN 301 549, die integraal overneemt en een gepubliceerde toegankelijkheidsverklaring vereist. De European Accessibility Act legt vergelijkbare verplichtingen op aan veel private diensten. In de praktijk komt iedereen op dezelfde plek uit: **WCAG 2.2 niveau AA is de norm**.

## De vier principes van WCAG

WCAG ordent alles onder vier begrippen, samen POUR genoemd. Ze zijn een bruikbare toets wanneer een
specifiek succescriterium niet direct van toepassing lijkt:

<dl>
  <dt>Perceivable (waarneembaar)</dt>
  <dd>
    De informatie komt aan, wat iemand ook kan zien of horen. Tekstalternatieven, ondertiteling,
    voldoende contrast, informatie die niet alleen door middel van kleur wordt gecommuniceerd.
  </dd>
  <dt>Operable (bedienbaar)</dt>
  <dd>
    De interface is te bedienen, hoe iemand dat ook doet. Toetsenbordtoegang, voldoende grote
    klikdoelen, geen korte tijdslimieten die je klemzetten, geen beweging die je niet kunt stoppen.
  </dd>
  <dt>Understandable (begrijpelijk)</dt>
  <dd>
    Gedrag en taal zijn voorspelbaar. Consistente navigatie, duidelijke labels, en foutmeldingen die
    uitleggen hoe je verder komt.
  </dd>
  <dt>Robust (robuust)</dt>
  <dd>
    Hulpsoftware kan het resultaat interpreteren. Geldige, semantische opmaak met kloppende namen,
    rollen en statussen.
  </dd>
</dl>
